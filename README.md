# Məzir — мобильное приложение

Интерактивный дизайн-прототип приложения для iPhone: рестораны, блюда, доставка и бронирование столов.

**Демо:** https://mazir-ios-design.vercel.app/

Это мобильный веб-прототип интерфейса iOS на React и TypeScript. Для просмотра достаточно браузера; проект не содержит нативную сборку Swift/Xcode или IPA.

## Возможности

- Четыре основные вкладки: Главная, Рестораны, Заказы и Профиль.
- Главная с горизонтальной лентой ресторанов и списком популярных блюд.
- Поиск, категории и фильтры в разделе Рестораны; избранное и бронирования доступны из профиля.
- Страницы заведений: меню, отзывы, информация и филиалы.
- Страницы блюд: состав, опции, острота, количество и добавление в корзину.
- Корзина, оформление, демонстрационная оплата и отслеживание заказа.
- Бронирование: дата, время, гости, зал и выбор столика.
- Адреса, бонусы, настройки и поддержка.
- Светлая, тёмная и системная темы с автоматической реакцией на оформление устройства.
- Настройки с редактированием аккаунта, выбором языка и темы, сведениями о приложении.
- Русский, казахский, английский, корейский и китайский языки.
- Макет iPhone на компьютере, полноэкранный интерфейс на телефоне, нижние вкладки и мобильные панели.

Язык и тема сохраняются в localStorage. Заказы, оплата, вход и бронирование работают в демонстрационном режиме: реальные операции и отправка данных на сервер не выполняются. Корзина и данные текущего сеанса хранятся в памяти.

## Локальный запуск

Требуется Node.js 22.13+ (рекомендуется Node.js 24) и npm.

```bash
npm ci
npm run dev
```

Откройте адрес, который покажет Vite в терминале.

```bash
npm run build      # Проверка TypeScript и production-сборка в dist/
npm run preview    # Просмотр production-сборки
npm run typecheck  # Отдельная проверка TypeScript
npm test           # Проверки маршрутов, тем и переводов
```

## Vercel

Импортируйте этот репозиторий в Vercel. Файл `vercel.json` задаёт команду `npm run build` и папку результата `dist`. Переменные окружения и серверная база данных не требуются.

Навигация использует URL-фрагменты, например `/#restaurant/1` и `/#restaurant/1/dish/1`, поэтому страницы можно открывать по прямой ссылке без серверного роутинга.

## Структура

- `app/page.tsx` — экраны приложения и демонстрационные сценарии.
- `app/ios-viewport.tsx`, `app/ios-overlays.tsx` — экран iPhone и мобильные панели.
- `app/preferences.tsx`, `app/i18n.ts`, `app/translations.json` — темы и переводы.
- `app/model.ts`, `app/navigation.ts` — данные, расчёты и маршруты.
- `app/globals.css` — оформление приложения.
- `components/ui/` — компоненты интерфейса.
- `public/` — изображения и иконка.
- `main.tsx`, `index.html`, `vite.config.ts` — запуск и сборка Vite.
